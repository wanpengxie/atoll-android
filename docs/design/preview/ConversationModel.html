时间线上到底有什么，手机上怎么摆

依据 ChannelReplica、ConversationPresentation、WorkspaceMapping 的实际逻辑整理。数据层一条不改，只改它在手机上的呈现：一个根请求的全部后代收进一张回合卡，复杂度分三层逐级展开。

1 · 账本行 request / response / event visibility=system 的行进叙述；无正文的行丢弃
2 · 折叠 回合 + 线程 请求 + 临时帧 + 第一个终态 = 回合；沿 parent_id 找到根，所有后代压平成根的线程
3 · 过滤 范围、Agent、隐藏规则 与我相关的关系索引；控制词、ui.*、排队消息、被取代的回合、父级未加载的行
4 · 聚合 挂载与合并 子任务挂到所属回合；孤儿子任务成组；瞬时事件只留最新；叙述合成一块
5 · 呈现（本次重做） 回合卡 + 三层披露 日期、连续、稳定 key、最新行不折叠；手机上最多一级缩进

三层披露

L0时间线：请求、回答正文（超过 18 行折叠）、状态，以及一条工作条（当前一步 + 计数片）
L1原地展开：点计数片，在卡内列出协作、子任务、调用，每项一行，最多一级缩进
L2底部面板：过程 · 协作 · 子任务 · 调用 · 账本，五个标签；深层线程用路径导航

“与我相关”怎么判定

种子：我发的、发给我的、成员主动发起的根对话。再沿 parent_id / correlation_id 走一跳。一个回合只要有一条相关，整张卡都保留。

Agent 筛选只在“与我相关”下可用：卡内任一消息的发送方或收件人命中即可。

新设计：筛选条显示被隐藏的数量，空结果给出一键切换。

滚动与位置

  • 跟随底部 / 浏览两种模式；“↓ N 条新动态”只数新回合根
  • 上翻预取历史；失败给“重试”；到顶显示“频道记录从这里开始”
  • 超过 5000 行切到历史窗口：顶部横幅“正在看历史 · 回到最新”，不显示运行中和等待状态
  • 每个视图（范围 + 筛选）各自记住位置；日期吸顶

手势

  • 右滑消息：回复（替代现在的“点按即回复”，避免误触）
  • 长按：操作面板（复制、星标、回复、编辑、停止、新建任务、过程）
  • 点计数片：原地展开；点状态或“过程”：底部面板
  • 每条消息下常驻的操作按钮取消
